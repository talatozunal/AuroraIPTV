# Aurora IPTV (macOS)

macOS 14+ için imzalı masaüstü uygulaması.

## İndirme

İmzalı `AuroraIPTVMac.app` paketi deponun
[Releases](https://github.com/talatozunal/AuroraIPTV/releases) bölümünde yer alır.

1. Releases bölümünden `AuroraIPTVMac.app.zip` dosyasını indirin.
2. Zip'i açıp `AuroraIPTVMac.app` dosyasını **Applications** klasörüne taşıyın.
3. İlk açılışta macOS, Apple Developer imzası nedeniyle normal uyarı gösterebilir;
   **System Settings → Privacy & Security → Open Anyway** ile onaylayın.

## Kullanım

1. Uygulamayı açın.
2. **Ayarlar → Playlist Ekle** ile M3U veya Xtream Codes hesabınızı ekleyin.
3. Kanal, film ve diziler ana ekranda listelenir.

> Uygulama paketinde playlist, sağlayıcı adresi veya hesap bilgisi bulunmaz.
> Tüm playlist verisi yalnızca sizin eklediğiniz içerikten oluşur ve cihazda saklanır.
